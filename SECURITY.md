# Security Policy

## Supported Versions

We actively patch security vulnerabilities in the latest release.

| Version | Supported |
| ------- | --------- |
| 1.x.x   | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

We take the security of our platform seriously. If you identify a vulnerability or security risk, please do not open a public GitHub issue. Instead, report it responsibly:

1. Send an email describing the vulnerability to **security@newshub.co** (or your security point of contact).
2. Include the following details in your report:
   * **Component affected**: e.g., FastAPI backend, React CORS headers, SQL queries.
   * **Steps to reproduce**: Complete descriptions, payload data, or script triggers.
   * **Impact details**: How this issue could be exploited (e.g. privilege escalation, API data leakage).

Once received, the security maintainers will acknowledge your report within 48 hours and coordinate a fix release within 14 days.
